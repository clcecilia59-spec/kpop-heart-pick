# K-pop 心动取向：互动挑战版 v10

这是一个可离线运行、适配移动端与小红书小工具容器限制的静态 Web 应用。

## 试玩

直接用浏览器打开 `index.html`，无需安装依赖或启动服务器。

## 已实现

- 6 个组合、46 位现役成员、92 张可追溯来源照片，每位成员至少 2 种风格
- TREASURE 10 人、Stray Kids 8 人、ENHYPEN 6 人、TOMORROW X TOGETHER 5 人、ATEEZ 8 人、THE BOYZ 9 人
- 每轮仍从 6 个组合各随机抽取 5 位不同成员，保持基础样本均衡
- 26 个混合挑战：12 个普通评分、3 个八秒限时题、6 个跨成员二选一、3 个同成员风格反差题、2 个神秘盲选
- 二选一和风格反差题只为选中照片记 2 分，未选照片不计分
- 评分后即时揭晓成员身份，并提供连续心动彩蛋与动态反馈
- 支持跳过、返回修改、进度保存和最终 Top 2 终极对决
- 心动鉴定书展示冠军、Top 3、风格偏好、本命浓度和隐藏组合偏爱
- 一键复制中文鉴定文案，适合截图或分享给朋友

## 素材与许可

照片来自各组合官方成员页或官方社交账号，具体链接见 `SOURCES.md`。官方公开发布不等于获得再发布授权；提交平台审核、公开推广或商业使用前，需要确认照片版权、艺人肖像及平台许可。

## 容器兼容约束

- 所有 JavaScript 均在外部 `.js` 文件中
- 所有交互通过 `addEventListener` 绑定
- 所有资源均在包内，无运行时网络请求
- 不使用 Worker、WebAssembly、iframe、外链或下载能力
