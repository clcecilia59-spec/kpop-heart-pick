# K-pop 匿名心动测试 v16（快速照片墙版）

这是一个可离线运行、适配移动端与小红书小工具容器限制的静态 Web 应用。

## 试玩

直接用浏览器打开 `index.html`，无需安装依赖或启动服务器。

## 已实现

- 6 个组合、46 位现役成员、92 张可追溯来源照片，每位成员至少 2 种风格
- TREASURE 10 人、Stray Kids 8 人、ENHYPEN 6 人、TOMORROW X TOGETHER 5 人、ATEEZ 8 人、THE BOYZ 9 人
- 封面使用纯图形“心动雷达”，不出现真人照片，以匿名盲测为核心趣味
- 46 位成员分成 6 屏照片墙，每屏同时浏览 6–8 位，避免逐题作答造成疲劳
- 点击照片可手动切换第二种风格；单击爱心标记“心动”，双击爱心升级为“本命”
- 第一阶段选择 8–16 位候选；双图相册复核后保留 6–14 位
- 双图复核后，为第一轮未选且没有看过第二面的候选提供一次双图翻盘机会
- 未晋级成员进入不显示团体信息的名字云，固定复活 2 位
- 晋级者分为四组进行照片抢位，每组只选 1 位，快速缩减到四强
- 四宫格淘汰者可再选 2 位复活，分别挑战暂定四强中的两个席位，最终仍保持四强
- 四强进行两场半决赛和一场冠军战，总共只需 7 次淘汰选择
- 抢位赛、半决赛和冠军战优先展示用户此前点为心动或本命的照片
- 除名字复活和最终揭晓外，所有页面均隐藏成员名和团名
- 支持返回照片墙修改选择、全程进度保存和冠军结果分享
- 每个主要步骤均可返回上一步，并恢复进入该步骤前的选择状态
- 心动鉴定书展示冠军、团体人均心动榜、主导风格与趣味审美反馈
- 结果页额外展示最终前三名，以及第一轮双击标记过的本命照片、姓名和团体
- 一键复制中文鉴定文案，适合截图或分享给朋友

## 素材与许可

照片来自各组合官方成员页或官方社交账号，具体链接见 `SOURCES.md`。官方公开发布不等于获得再发布授权；提交平台审核、公开推广或商业使用前，需要确认照片版权、艺人肖像及平台许可。

## 容器兼容约束

- 所有 JavaScript 均在外部 `.js` 文件中
- 所有交互通过 `addEventListener` 绑定
- 所有资源均在包内，无运行时网络请求
- 不使用 Worker、WebAssembly、iframe、外链或下载能力
